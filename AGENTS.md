# Impressao-Biel

- App de página única: tudo (CSS, JS, html2canvas inline) vive em `index.html`. Não há build nem dependências — basta abrir o arquivo / usar preview estático.
- Git/remote: `origin` = `https://github.com/alebitencourtx/impressoes-biel.git`. Autenticação no sandbox é via `git config --global credential.helper store` + `~/.git-credentials` (fora do repo, chmod 600). O token **nunca** entra em arquivo do projeto nem no `AGENTS.md`. A branch de trabalho é `feat/figurinhas-extrator-reutilizavel`; `main` só recebe por PR. Push sem prompt: `GIT_TERMINAL_PROMPT=0 git push`.
- Terminal do app (Android): o Enter do teclado manda `\n` e o pty não executa — use o botão `→|` da barra de ferramentas para rodar o comando.
- Folha A4 medida em **mm**. O emoji (`type: 'sticker'` sem `src`) **não guarda** tamanho de fonte: `emojiFit()` deriva a fonte de `w`/`h` e a centraliza com `translate(dx, dy)`, de modo que a **tinta** do glifo preencha a caixa (~98%) sem ser cortada.
- Medir o emoji: `measureEmoji()` desenha o glifo num canvas 4×REF e varre os pixels pintados. **Não usar `measureText().actualBoundingBox*`** — em fontes de emoji ele devolve uma caixa quadrada (1.18em) em vez da tinta, e o resultado estoura a caixa (emoji cortado).
- O texto é centralizado pelo *advance* (caixa da fonte), e a tinta do emoji é assimétrica (o 🐶 vaza ~0,08em à direita): por isso a medição é relativa à origem do texto e o `dx` corrige o centro.
- O arrasto de redimensionar usa **apenas `paintGeometry`** (não recria o nó): qualquer propriedade que dependa da caixa precisa ser reaplicada ali — é o caso do `font-size`/transform do emoji (via `paintEmojiFont`).
- Figurinhas de imagem (`type: 'sticker'` com `src`) usam a **caixa inteira, sem `scale`**: o `scale(1.35)` antigo fazia a arte transbordar a caixa e cortar. O recorte já vem com respiro transparente dentro do quadrado.
- Blobs de figurinha: `OFFLINE_MAPS` (no topo do script) é a **única** lista de `window.OFFLINE_*`; `figurinhasData()` funde tudo num mapa `nome-do-arquivo → data URL`. Categoria nova = array + `STICKERS['Nome'] = { tipo:'imagem', dir, itens }` + nome do blob em `OFFLINE_MAPS` + `node tools/pack-stickers.js <pasta> --embed`. O item guarda o **caminho**, nunca o data URL. Pipeline completo em `FIGURINHAS.md`.
- **Não** remover o `src` do item achando que "é só o blob": `localStorage` guarda o caminho e `figurinhaSrc()` resolve para o data URL na hora de pintar.
- A UI de fundo foi **removida** (papel sempre branco) e `applyBackground()` só pinta branco. Sobraram `el.bgType`/`el.bgSolid`/`el.bgGrad*` em `const el = {…}` apontando para elementos que não existem mais: **nunca** chame método/`.value` neles — era assim que `init()` morria na primeira linha (TypeError em `null`), levando `bindControls()` e `renderAll()` junto.
- Estado em `localStorage`; em `load()` os campos antigos `fontSize`/`fu`/`fsRatio` do emoji são descartados.
- Alças de canto 38 px e de rotação 42 px (CSS em `.item__handle`); o raio de toque é `handleAt()` (`min(30, max(16, menor lado/3))`). Ao mudar o tamanho da alça, ajuste o `top/left` negativo (metade do tamanho) e o `margin-left` da alça de rotação.
- Manifesto: `id: "impressao-biel-app"` é **único e do próprio site** (resolve para `<host>/impressoes-biel/impressao-biel-app`). Não voltar para `"./"`: o id é o que impede o Chrome de tratar este app como o mesmo de outro GitHub Pages já instalado.
- **Service worker (opcional)**: existe só para o app funcionar offline/instalado. `sw.js` é **rede primeiro** (`fetch` com `cache: 'no-cache'`, cache só como reserva offline) — nunca sirva cache antes da rede, senão "recarregar" mostra a versão velha. Ao mexer no `sw.js`, suba o `CACHE_NAME` (o `activate` apaga os caches antigos). Abas o app com `?nocache` na URL para desregistrar o SW e apagar todos os caches (modo "sempre do zero"). Para tirar o SW de vez, apague `sw.js` e o bloco de registro em `init()`.
